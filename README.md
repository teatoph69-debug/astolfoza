# 🪰 МУХА × Rhythia

**Aim-ритм игра в стиле Rhythia прямо в браузере + МУХА: нейросеть, которая учится играть у тебя на глазах.**

Ноты летят на тебя по сетке 3×3, ты ведёшь курсор мышкой и собираешь их в ритм музыки. Правила и константы взяты
из исходников Sound Space Plus / Rhythia: хитбокс 1.1375, окно попадания 55 мс, 5 HP, множитель до 8×.
Рядом живёт **МУХА**. Это нейросеть с «рукой», у которой ограничены скорость и ускорение, поэтому
телепортироваться она не может. Играть ей приходится, как человеку: предугадывать ноты, вовремя тормозить и срезать углы через хитбоксы.

Всё работает **из коробки**: ничего не нужно ставить, игра сделана одним HTML-файлом и работает даже офлайн.

## ▶ Как запустить

| Способ | Что сделать |
|---|---|
| **Скачать и играть** | Скачай [`dist/index.html`](dist/index.html) и открой двойным кликом (Chrome / Edge / Firefox). |
| **GitHub Pages** | Settings → Pages → Source: *GitHub Actions*. После пуша в `main` игра будет жить по ссылке `https://<ник>.github.io/<репо>/`. |
| **Для разработки** | `npm install && npm run dev`, дальше открой http://localhost:5173 |

## 🎮 Что внутри

- **Играть** на 7 встроенных треках. Музыка генерируется синтезатором прямо в браузере
  (синтвейв, драм-н-бейс, хаус, чиптюн…), у каждого трека 5 сложностей: *Легко → Экстрим*.
- **Свои карты из Rhythia**: просто перетащи в окно `.sspm` (v1 и v2), `.rhm`, старые `.txt` карты Sound Space.
- **Любая песня → карта**: брось mp3/ogg/wav, и МУХА сама найдёт биты, определит BPM и сделает карты на 5 сложностей.
- **Смотреть, как играет МУХА**: пунктирные «линии зрения» показывают, какие ноты она сейчас планирует.
- **Против МУХИ**: играете одну карту одновременно, её курсор виден призраком, наверху «перетягивание каната» по очкам.
- **Моды**: Speed, No Fail, Hard Rock, Mirror. Настройки AR, дальности, параллакса, чувствительности, цветов нот и оффсета
  с калибровкой.

## 🧠 МУХА: Лаборатория (обучение в реальном времени)

Нажми **«Обучать»** и смотри, как она растёт:

1. В каждом **поколении** ~48 мутантов её мозга играют одни и те же короткие отрывки карт.
2. Мутанты, которые попали лучше, тянут мозг в сторону своей мутации (**Evolution Strategies**, как у OpenAI).
3. **Учебная программа** (curriculum): освоила уровень, получает сложнее. Карты генерируются от 0★ до 20★.
4. Раз в несколько поколений проходит **экзамен** на фиксированном наборе карт 0…20★.
   **★ Навык** = самая сложная карта, которую она проходит с точностью ≥ 90 %.
5. По навыку она получает **звания**: 🥚 Личинка → 🐛 Куколка → 🪰 Муха-новичок → … → 👑 Легенда Rhythia →
   🌌 Повелитель сетки → ⭐ Бог ритма → 💎 Абсолют.

Всё видно вживую: арена, где текущий мозг играет прямо сейчас, графики точности и навыка, «что она умеет»
по уровням и сама нейросеть, в которой загораются нейроны. Прогресс сохраняется в браузере, мозг можно скачать
и загрузить файлом.

В игре уже есть **предобученные мозги** (обучены `tools/train.mjs`) для трёх «рук»:
*человеческой*, *топ-игрока* и *кибер-руки*, которой физически доступно всё.

## 🗺 Где брать карты

[rhythia.com/maps](https://www.rhythia.com/maps) → скачай `.sspm` → перетащи в игру. Ещё карты лежат в Discord сообществе Rhythia.

> ⚠️ МУХА играет **только внутри этой игры**. Не используй ботов в настоящей Rhythia: за это там банят,
> и это нечестно по отношению к игрокам.

## 🛠 Разработка

```bash
npm install
npm run dev        # dev-сервер с пересборкой на каждое обновление страницы
npm test           # юнит-тесты (судейство, парсеры карт, авто-маппер, ИИ)
npm run build      # → dist/index.html (один самодостаточный файл)
npm run train -- --gens 1500 --hand pro --out checkpoints/pro.json   # обучить МУХУ в Node на всех ядрах
```

```
src/
  core/      судейство (Judge), константы Rhythia, модель карты, расчёт звёзд
  ai/        нейросеть (MLP), «рука» и пилот, Evolution Strategies, curriculum, воркеры
  maps/      парсеры .sspm / .rhm / .txt, авто-маппер (onset detection + BPM), генератор паттернов
  audio/     аудио-движок, процедурный синтезатор и треки
  render/    3D-поле на Canvas (туннель, ноты, курсоры, эффекты)
  ui/        экраны: меню, выбор карты, игра, результаты, Лаборатория, настройки
tools/       сборка в один файл, обучение в Node
```

*English:* a browser Rhythia-style aim rhythm game plus МУХА ("the Fly"), a neural network that learns to play it
live with evolution strategies. Open `dist/index.html` and play, or train her in the AI Lab.
